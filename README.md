# Ultraplay

Ultraplay is a gaming community starter app. This repository includes a lightweight web application setup for local development and production builds.

## Build and development

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

The app will run at the local Vite URL shown in the terminal.

### Build the production bundle

```bash
npm run build
```

### Preview the production build locally

```bash
npm run preview
```

## Project structure

- `index.html` — app shell
- `src/main.js` — application entry point
- `src/styles.css` — styling for the landing page
- `package.json` — project scripts and dependencies

## Notes

This starter is intentionally simple and ready to expand as the community platform grows.
